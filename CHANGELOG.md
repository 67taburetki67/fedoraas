# Что менялось

## Не выпущено

- Клавиши громкости и яркости (Fn+F1, F2, F3, F5, F6) работают с плашкой на экране. Стандартные привязки из `hyprland.lua` снимаются, чтобы шаг не срабатывал дважды. Для виртуальной машины то же самое на `SUPER+SHIFT+F1…F6`.
- Повторный запуск `install.sh` больше не сбрасывает выбранную тему на gray.

## 1.0

Установка и откат
- Установщик больше не виснет на этапе тем: причиной был `swaync-client -rs` без запущенного swaync. Теперь клиент вызывается только при живом демоне и с таймаутом, а при установке сессию не перезагружают.
- Перед установкой делается проверенная резервная копия; без неё ничего не меняется. Пакеты делятся на обязательные и необязательные, в конце выводится сводка. Раскладка клавиатуры проверяется.
- Повторная установка удаляет файлы, которых в новой версии уже нет (список установленного хранится в `~/.local/share/fedoraas/manifest`).
- `uninstall.sh` удаляет только поставленное установщиком, чистит свои строки в `hyprland.lua` и `.bashrc`, возвращает тему GTK, курсор и шрифт.
- Fedora 45: алиас `hypr` запускает Hyprland через `kmscon-launch-gui`.

Темы
- `theme` читает `.env` как данные, а не исполняет; применяет тему целиком или никак; экранирует значения; сразу перекрашивает открытые терминалы (foot, kitty).
- `theme-gen` проверяет ввод и не перезаписывает существующую тему без `--force`.

Оболочка
- Заметки: убрана гонка при миграции старых данных, добавлены версия формата, проверка структуры, копия `boards.json.bak`; повреждённый файл сохраняется рядом. Переключение между голосовыми заметками исправлено.
- Виджеты: карточки не выходят за экран; панель настройки переключается вверх/вниз; повреждённый `widgets.json` не ломает оболочку. Погода запрашивается только при включённом виджете.
- Wi-Fi: пароль не попадает в аргументы процесса, сохранённые сети находятся по SSID, ошибки команд показываются с кодом, зависшие команды прерываются.
- Лаунчер: калькулятор без `eval`.
- Waybar показывает все 10 рабочих столов.

Убрано
- Экранный шейдер (зерно и оттенок) и автоблокировка (hypridle): ничего не блокирует и не выключает экран само.

Прочее
- Службы райса (`supervise`) никогда не сдаются: при частых падениях делают паузу 30 секунд и пробуют снова.
- Тесты `tests/run.sh` и проверка в GitHub Actions.
