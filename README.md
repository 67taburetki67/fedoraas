# fedoraas

![ci](https://github.com/67taburetki67/fedoraas/actions/workflows/ci.yml/badge.svg)

Тёмный минималистичный рабочий стол на **Hyprland** и **Quickshell** для **Fedora 44/45**: оверлей-виджеты, быстрые настройки, плеер с визуализатором, заметки-холст с фото и GIF, свой лаунчер, шпаргалка клавиш и 16 цветовых тем. Ставится одной командой и откатывается одной командой.

## Возможности

- **Виджеты (`SUPER+W`):** часы, календарь, погода, нагрузка, график, плеер, помодоро, задачи, заметки, быстрые приложения, система. Карточки двигаются и меняют размер мышью, у каждой свои прозрачность и фон.
- **Быстрые настройки (`SUPER+N`):** Wi-Fi, Bluetooth, звук, яркость, питание.
- **Лаунчер (`SUPER+D`):** приложения, калькулятор, `> команда`, `? поиск в интернете`.
- **Заметки (`SUPER+O`):** холст с текстом, фото, GIF и голосовыми записями.
- **Плеер (`SUPER+A`)** с визуализатором (через playerctl и cava).
- **Темы:** переключаются командой `theme`, перекрашивают панель, терминал, GTK, Qt и экран блокировки. Свою тему делает `theme-gen`.
- **Без сюрпризов:** ничего не блокирует и не выключает экран само, службы райса перезапускаются при падении.

## Требования

- Fedora 44 или 45, обычный пользователь с `sudo`.
- Hyprland в официальных репозиториях Fedora может не быть: установщик предложит подключить COPR.
- Проверено в виртуальной машине (QEMU/KVM, virt-manager). На реальном железе, особенно с гибридной графикой NVIDIA, не проверялось.

## Установка

```bash
git clone https://github.com/67taburetki67/fedoraas.git
cd fedoraas
./install.sh
```

Параметры:

| Параметр | Что делает |
|---|---|
| `--yes` | без вопросов (раскладка `us,ru`) |
| `--layout us,ru` | раскладки клавиатуры |
| `--no-packages` | только скопировать конфиги, пакеты не ставить |
| `--with-lock` | поставить hyprlock для ручной блокировки экрана |
| `--dry-run` | показать план и выйти |

Перед изменениями установщик делает проверенную резервную копию (`~/.rice-backup-*.tar.gz`), делит пакеты на обязательные и необязательные и в конце показывает сводку: что установилось, а что нет и какой функции из-за этого не будет.

## Запуск

Выйди из текущей сессии или перейди в консоль (`Ctrl+Alt+F3`), открой **новый** терминал (чтобы подхватился `~/.bashrc`) и набери:

```bash
hypr
```

Это алиас, который создаёт установщик. На Fedora 45 консоль работает через kmscon, и обычный `start-hyprland` падает с ошибкой `CBackend::create() failed`, поэтому алиас запускает `kmscon-launch-gui start-hyprland`. На Fedora 44 он просто вызывает `start-hyprland`. Если алиаса нет (другая оболочка, например zsh), запусти нужную команду напрямую.

## Клавиши

Полный список открывается по `SUPER+/`.

| Клавиши | Действие |
|---|---|
| `SUPER+Q` | терминал |
| `SUPER+D` / `SUPER+R` | лаунчер |
| `SUPER+W` | виджеты, темы, обои, наклейки |
| `SUPER+N` | быстрые настройки |
| `SUPER+O` | заметки |
| `SUPER+A` | плеер |
| `SUPER+/` | шпаргалка клавиш |
| `SUPER+C`, `V`, `F` | закрыть, плавающее, во весь экран |
| `SUPER+1…0` | рабочие столы |
| `SUPER+SHIFT+P` | лёгкий режим: без блюра, теней и анимаций |
| `SUPER+M` | выйти из Hyprland |

## Темы и обои

```bash
theme purple              # сменить тему (или кнопки в SUPER+W)
theme list                # все темы
theme wall next           # следующие обои в теме
theme-gen sunset 15 70    # своя тема: оттенок 0-360, насыщенность 0-100
```

Обои лежат в `~/.config/themes/wallpapers/<тема>/`. При установке там создаётся простой градиент, свои картинки (png, jpg) просто положи туда.

## Виртуальная машина

Работает в QEMU/KVM (virt-manager). Установщик сам видит виртуалку и:

- задаёт монитор `Virtual-1` и запускает Quickshell на программном рендере;
- добавляет в `~/.config/hypr/layout.lua` строку `LIBGL_ALWAYS_SOFTWARE=1`, без неё kitty и другие GL-программы могут падать с ошибкой EGL. Если у тебя всё работает и без неё, строку можно удалить.

Если вставка в окно ВМ не работает, удобнее всего работать по SSH с основной системы (`ssh пользователь@адрес`), а файлы отправлять через `scp`. Адрес ВМ покажет `ip -4 a` внутри неё.

## Если что-то сломалось

```bash
rice-check                  # проверка всего; rice-check --fix чинит безопасное
rice status                 # какие службы работают
rice restart quickshell     # перезапуск оболочки
rice logs quickshell        # её последние сообщения
```

`SUPER+SHIFT+R` выходит из режима виджетов, если он завис. Проверки без Hyprland запускает `tests/run.sh`.

## Удаление

```bash
./uninstall.sh --dry-run    # показать, что будет удалено
./uninstall.sh
```

Откат удаляет только то, что поставил установщик (по списку), убирает свои строки из `hyprland.lua` и `~/.bashrc`, возвращает тему GTK, курсор и шрифт. Твои обои, заметки и собственные темы остаются. Установленные пакеты не удаляются.

## Устройство репозитория

```
dotfiles/config/    конфигурации (Hyprland, Quickshell, Waybar, swaync, шаблоны тем)
dotfiles/local/bin/ команды: theme, theme-gen, rice, rice-check, supervise, shot.sh...
install.sh          установщик
uninstall.sh        откат
tests/run.sh        проверки без Hyprland
CHANGELOG.md        что менялось
```
