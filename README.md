# Quickshell-райс для Hyprland (Fedora)

Тёмный минималистичный рабочий стол: оверлей-виджеты по `SUPER+W`, быстрые настройки, плеер с визуализатором, заметки-холст с фото и GIF, свой лаунчер, шпаргалка клавиш и **16+ цветовых тем** (серая, синяя, зелёная, фиолетовая, бирюзовая, коричневая, оранжевая, розовая... и кошачья с лапками).

> Статус: бета. Проверено в виртуальной машине на Fedora 44. На реальном железе, особенно с гибридной графикой NVIDIA, не проверялось. Экран блокировки по умолчанию отключён.

## Известные баги
Неработающий запуск на Fedora 45 из-за kmscon (Временный фикс - kmscon-launch-gui start-hyprland)
Бесконечное создание обоев из-за swaync-client -rs которое вызывалось theme gray временный фикс - pkill swaync-client из второй консоли
## Установка (Fedora 44+)

```bash
git clone https://github.com/67taburetki67/fedoraas.git rice && cd rice
./install.sh            # спросит про раскладку клавиатуры и COPR для Hyprland
```
Параметры: `--yes` (без вопросов), `--with-lock` (экран блокировки), `--layout us,ru`, `--no-packages`, `--dry-run`.

Ставится: Hyprland, Quickshell, Waybar, swaync, foot, btop, fastfetch, Mousepad (блокнот), Thunar, Loupe (картинки), Evince (PDF), mpv (видео и музыка), File Roller (архивы). Видео с нестандартными кодеками может потребовать репозиторий RPM Fusion.

Запуск: перейди в TTY (`Ctrl+Alt+F3`) и выполни `start-hyprland`. На Fedora Workstation Hyprland может появиться в списке сессий.

## Клавиши (полный список: `SUPER+/`)

| Клавиши | Действие |
|---|---|
| `SUPER+Q` | терминал |
| `SUPER+D` / `SUPER+R` | лаунчер (приложения, калькулятор, `> команда`, `? поиск`) |
| `SUPER+W` | виджеты, темы, обои, наклейки (кнопка «настроить») |
| `SUPER+N` | быстрые настройки (Wi-Fi, Bluetooth, звук, питание) |
| `SUPER+A` | плеер |
| `SUPER+O` | заметки (холст: текст, фото, GIF, голосовые) |
| `SUPER+/` | шпаргалка клавиш |
| `SUPER+C`, `V`, `F` | закрыть, плавающее, во весь экран |
| `SUPER+1…0` | рабочие столы |
| `SUPER+SHIFT+P` | лёгкий режим (без блюра, теней, анимаций) |
| `SUPER+M` | выйти из Hyprland |

## Темы и обои

```bash
theme purple          # переключить тему (или кнопки в SUPER+W)
theme wall next       # следующие обои в теме
theme-gen sunset 15 70   # своя тема: оттенок 0-360, насыщенность 0-100
```
Обои темы лежат в `~/.config/themes/wallpapers/<тема>/`. При установке там создаётся простой градиент, положи свои картинки, и тема их подхватит.

## Если что-то сломалось

```bash
rice-check            # проверка всего; rice-check --fix чинит безопасное
rice status           # какие службы работают
rice restart quickshell
rice logs quickshell
```
Аварийный выход из режима меню виджетов: `SUPER+SHIFT+R`. Откат установки: `./uninstall.sh`.
